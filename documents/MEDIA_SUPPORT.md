# 파일 열람과 미디어 지원

[문서 목차로 돌아가기](./INDEX.md)

## 지원 형식

| 종류 | 지원 확장자 | 허용 MIME 타입 |
| --- | --- | --- |
| 이미지 | `.jpg`, `.jpeg`, `.jfif`, `.png`, `.gif`, `.webp`, `.avif`, `.bmp` | `image/jpeg`, `image/png`, `image/gif`, `image/webp`, `image/avif`, `image/bmp` |
| 영상 | `.mp4`, `.webm`, `.ogg`, `.ogv` | `video/mp4`, `video/webm`, `video/ogg` |

이미지·영상 뷰어 지원 여부는 업로드할 때 저장된 MIME 타입으로 판단합니다.
SVG는 실행 가능한 내용을 포함할 수 있으므로 인라인으로 표시하지 않습니다.
영상 재생 여부는 브라우저가 지원하는 컨테이너와 코덱에 따라 달라집니다.

## 텍스트 메모장

데스크톱·모바일·게스트에서 다음 확장자를 읽기 전용 메모장으로 엽니다.

- `.txt`, `.json`, `.md`, `.markdown`, `.log`, `.csv`, `.tsv`
- `.yaml`, `.yml`, `.xml`, `.ini`, `.conf`, `.toml`

확장자의 대소문자는 구분하지 않습니다. 확장자로 판별되지 않아도 `text/*`,
`application/json`, `application/xml`, `application/yaml`, `application/toml`
MIME이면 텍스트로 엽니다. 이미지·영상 MIME의 기존 처리 규칙은 우선합니다.

최대 2MiB의 UTF-8 파일을 지원하며 UTF-8 BOM도 처리합니다. 다른 인코딩이나
바이너리 데이터는 안내 후 원본을 다운로드할 수 있습니다. 크기 제한은
`src/client/constants/filesystem/text/text-file.ts`에서 관리합니다.

JSON·Markdown·HTML을 가공하거나 실행하지 않고 원문을 표시합니다. 전체 복사와
다운로드를 제공하며, 원본 파일 편집·저장은 지원하지 않습니다. 데스크톱은 긴 줄을
가로로 스크롤하고 모바일은 화면 폭에 맞춰 줄바꿈합니다.

메모장은 R2 일반 파일을 읽으며 D1 메모 프로그램으로 변환하지 않습니다. 창 상태는
세션에서만 유지합니다. 게스트는 공개된 파일에만 접근할 수 있습니다.

뷰어·메모장이 지원하지 않는 파일은 다운로드 여부를 묻습니다. 사용자가 명시적으로
누른 다운로드 명령에는 추가 확인을 표시하지 않습니다.

## 이미지 뷰어

- 확대·축소, 창 맞춤과 회전을 지원합니다.
- 데스크톱에서는 같은 폴더의 지원 미디어를 저장된 정렬 순서로 탐색합니다.
- 모바일에서는 좌우 스와이프로 이전·다음 이미지로 이동합니다.
- 원본과 썸네일은 소유자 또는 허용된 게스트 API를 통해 비공개로 전송합니다.

## 영상 뷰어

- 데스크톱은 XP형 재생 컨트롤과 이전·다음 미디어 이동을 지원합니다.
- 모바일은 브라우저의 기본 영상 재생 컨트롤을 사용합니다.
- 단일 HTTP Range 요청을 지원합니다.

## 썸네일

Cloudflare Images로 JPEG, PNG, GIF와 WebP 이미지를 최대 96×96px 정적 WebP
썸네일로 변환합니다. GIF와 애니메이션 WebP는 첫 프레임만 사용합니다.
화면에 보이는 항목부터 불러오며, 생성된 썸네일은 비공개 R2 객체로 저장해
다시 사용합니다.

20MB를 초과한 이미지와 BMP·AVIF는 일반 파일 아이콘으로 표시될 수 있지만,
지원 MIME이라면 원본 이미지 뷰어는 계속 사용할 수 있습니다.
